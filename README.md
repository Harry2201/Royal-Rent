# Royale Rent — Designer Dress Rentals

Luxury Indian wedding fashion rental marketplace. Frontend: **React + Vite** in `frontend/`.

## Quick start

```bash
cd frontend
npm install
npm run dev
```

See [frontend/README.md](frontend/README.md) for architecture, demo logins, and backend integration.

## Highlights

- Marketplace: explore, dress details, wishlist, booking requests
- Owner flow: multi-step upload, my listings, earnings dashboard
- JWT-ready API layer (Axios + mock data, switchable via `.env`)
- Role-based routes: customer, dress owner, admin
- Original royal landing page preserved
